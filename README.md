## About

I build software around real processes — usually the kind that still runs on manual work, scattered documents and spreadsheets.

Most of what I do sits between the backend and the data: APIs in Python, relational modeling in SQL, pipelines that read and produce documents, and automation that removes the step someone was doing by hand. I care about understanding the problem before writing the code, and I'd rather ship something that holds up in production than something that only looks good in a demo.

Based in Brazil · Working mainly with Python, FastAPI, MySQL and AI-assisted processing.

## AI & Automation

I work with the **Claude API** inside real processing flows — document analysis, information extraction and structured content generation, with validation steps around the model instead of trusting a single call. The interesting part isn't the prompt; it's the pipeline around it: what gets sent, what gets checked, and what happens when the output is wrong.

On the automation side I use **n8n** to connect services and remove repetitive steps from a process. My interest isn't only in writing code — it's in making a process stop requiring a person to babysit it.

## SQL & Data

Day to day I work with **SQL** and **MySQL** for modeling and querying, **Pandas** for cleaning and transforming datasets, and Excel where the data still arrives that way. This supports the systems I build rather than being a separate track — it's how the data gets from wherever it lives into something an application can use.
